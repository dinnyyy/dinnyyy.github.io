# dinnyyy.github.io

Personal portfolio site for **Joshua Dinn**, a second résumé covering projects,
experience, and certifications. Built as a single scrollable page with anchored
navigation.

**Live:** https://dinnyyy.github.io/

## Stack

Plain static HTML, CSS, and vanilla JavaScript. No build step, no dependencies.
Served directly by GitHub Pages from the `main` branch (user site).

## Structure

```
.
├── index.html            # The whole site (single page, anchored sections)
├── css/styles.css        # Design tokens (shadcn/ui naming) + layout; light first, dark toggle
├── js/main.js            # Theme toggle, mobile menu, scrollspy
├── assets/
│   ├── fonts/            # Atkinson Hyperlegible Next (self-hosted, SIL OFL)
│   ├── img/              # Project art (generated SVGs) + photos
│   ├── resume/           # Downloadable résumé (software engineering)
│   ├── certs/            # Certificate PDFs + images
│   └── projects/         # Project supporting files (e.g. GARCH report PDF)
├── tools/                # Scripts that generate the project SVGs
└── .nojekyll             # Serve files as-is (skip Jekyll processing)
```

## Editing content

All content lives in `index.html`, grouped by `<section>`. Search for the section
id (`#about`, `#experience`, `#projects`, `#certifications`, `#contact`) to jump to it.

### Project images

The JackTen, OLS vs MLE, trading bot and GARCH images are SVGs generated by
plain Node scripts (no dependencies). Edit the script, then rebuild:

```bash
node tools/charts.js    # ols-vs-mle.svg, trading-bot.svg, volatility.svg
node tools/jackten.js   # jackten.svg
```

To use a real screenshot instead, drop it into `assets/img/` and update the
`src`, `width` and `height` on that project's `<img>`.

### Colours and type

All colours are CSS variables at the top of `css/styles.css`, named the way
shadcn/ui names them (`--background`, `--foreground`, `--primary`,
`--muted-foreground`, `--border`, `--ring`, `--radius`). The `.dark` block
redefines them for dark mode.

## Local preview

Any static server works, e.g.:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/.
